## 🚀 About Me

Sou Desenvolvedor de Software e estudante de Ciência da Computação no CEFET/RJ, com experiência no desenvolvimento de aplicações backend, APIs REST e soluções baseadas em Inteligência Artificial.

Tenho experiência prática principalmente com Python, FastAPI, APIs REST, bancos de dados SQL e NoSQL, além da integração de LLMs e agentes de IA utilizando OpenAI, Anthropic, Gemini, CrewAI e AtendentePro.

Também atuo com automação de processos, integração de sistemas via APIs e Webhooks, pipelines de dados e IA e desenvolvimento de soluções em nuvem.

Ao longo da minha experiência profissional, participei do desenvolvimento de sistemas utilizados por mais de 300 mil usuários, plataformas de agentes de IA e soluções de automação.

### 💡 Experience Highlights

- 🤖 AI & LLMs: Integração de OpenAI, Anthropic e Gemini em aplicações e agentes de IA.
- ⚙️ Backend Development: Desenvolvimento de APIs REST e serviços utilizando Python, FastAPI e bancos de dados SQL/NoSQL.
- 🔗 System Integration: Integração de APIs, Webhooks e serviços externos para automação de processos.
- ☁️ Cloud: Experiência com Azure Functions e conhecimentos em AWS.
- 📊 Data & Machine Learning: Análise e processamento de dados com Pandas, NumPy e Scikit-learn.
- 🔬 Research: Bolsista de Iniciação Científica com pesquisa aplicada à análise de dados esportivos.
